# C# .Net Library
A collection of tools and common classes for developing .Net applications.

## Requirements

Version 0.13.0 and later require .NET 10 and DigitalProduction.Xml.XInclude 1.2.0 or later. Build with the .NET 10 SDK and its default C# 14 language version.

Version 0.12.5 is the final .NET 9 release and is no longer maintained.
